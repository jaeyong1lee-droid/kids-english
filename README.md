# 🌟 초등 3~6학년 매일 10분 영어 학습지 (A4 출력용 웹 서비스)

초등학교 3학년부터 6학년까지 아이들이 매일 스스로 **A4 세로 1장**씩 인쇄하여 공부할 수 있는 스마트 영어 학습지 생성 웹 플랫폼입니다.

---

## 🎯 학습지 3단락 구성 안내

### 1️⃣ 1단락: 말장난 쏙쏙 연상 영단어 (3개)
- **아이디어**: 영어 단어의 소리/발음과 우리말 뜻을 유머러스하게 연결한 연상 암기법
- **예시**:
  - `blunder` [블런더]: **실수하면 불난다!** ➡️ 큰 실수, 실수하다
  - `protect` [프로텍트]: **프로처럼 텍(딱) 막아서 지키다!** ➡️ 보호하다, 지키다
  - `whisper` [휘스퍼]: **귓가에 휘~ 스르륵 바람 불며 속삭이다!** ➡️ 속삭이다
- 단어, 한글 발음, 품사, 연상 비법 문장, 초등학생 맞춤 실생활 예문과 해석 제공

### 2️⃣ 2단락: 입에서 술술~ 통문장 생활영어 (2개)
- **아이디어**: 일상생활, 학교, 가정에서 생각하지 않고 입으로 바로 튀어나오는 실전 필수 표현 통째로 외우기
- **예시**:
  - 상황: 선생님이나 친구에게 질문할 때 ➡️ **"Let me ask something."** (제가 질문 하나 해도 될까요?)
  - 상황: 순서를 지켜 놀이할 때 ➡️ **"Let's take turns."** (우리 차례대로 번갈아 가며 하자.)
- 통문장 핵심 표현, 자연스러운 발음 꿀팁, 짧은 2줄 미니 대화(A/B) 제공

### 3️⃣ 3단락: 공책 반접기 4단 단어 암기장 (4열 표)
- **학습 가이드 문구**:
  > *"공책을 세로로 접어 4칸을 만든 뒤 1칸(영어) → 2칸(한글 뜻 쓰기) → 1칸을 접어서 가리고 2칸의 한글만 보며 3칸(영어 쓰기) 순서로 진행해 보세요."*
- **4열 표 구조**:
  - **1칸: 영어 단어** (AI가 사전 인쇄: 오늘 1단락 단어 3개 + 이전 복습 누적 단어 총 7~8개)
  - **2칸: 한글 뜻 쓰기** (학생이 직접 연필로 적는 빈칸)
  - **3칸: 1칸 접고 영어 쓰기** (1칸을 가린 뒤 2칸 뜻만 보고 스스로 영어 철자를 적는 빈칸)
  - **4칸: 채점 & 재도전** (채점 체크 및 오답 다시 쓰기 빈칸)
- **스마트 망각 방지(반복 복습)**:
  - 이전에 학습했던 단어들이 Neon DB 단어장에 누적 저장되어, 새 학습지를 만들 때 자연스럽게 3단락에 섞여 반복 출제됩니다.

## 🚀 빠른 실행 방법

### 로컬 실행 (Windows)
1. 바탕화면이나 탐색기에서 **`start.bat`** 파일을 더블 클릭합니다.
2. 백엔드(포트 5001) 및 프론트엔드(포트 3001)가 자동으로 켜지고, 기본 웹 브라우저로 `http://localhost:3001` 이 자동으로 열립니다.

### 인쇄 방법
- 브라우저 상단의 **[A4 인쇄하기]** 버튼을 클릭하거나 `Ctrl + P`를 누릅니다.
- 용지 크기: `A4`, 방향: `세로(Portrait)` 선택 후 인쇄하시면 여백 잘림 없이 1장에 꼭 맞게 출력됩니다.
- 상단의 **[정답 보기]** 버튼을 누르면 3단락 2칸(뜻)과 3칸(영어)에 정답이 표시되어 부모님/선생님용 정답지로도 출력 가능합니다.

## 🛠️ 기술 사양 및 인프라

- **Frontend**: React 18, Vite, Tailwind CSS, Lucide React (A4 전용 인쇄 CSS 미디어 쿼리 적용)
- **Backend**: Node.js, Express, PostgreSQL (`pg`)
- **AI Engine**: Google Gemini API (`@google/generative-ai`), 복수 API 키 및 자동 폴백 지원
- **Database**: Neon Serverless PostgreSQL (`안티` 프로젝트와 동일한 네온 DB 사용, `kids_english_sheets` 및 `kids_english_words` 분리 테이블로 안전하게 운용)
- **Deployment**: Vercel 배포 완벽 대응 (`vercel.json` 사전 설정 완료)
